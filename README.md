# Vera Cherni Consultancy Landing Page

A modern, professional single-page landing page for Vera Cherni Consultancy Services.

## Features

- **Modern Design**: Ultra-modern, minimalist design with high contrast
- **Responsive**: Mobile-first responsive design using Tailwind CSS
- **Animations**: Subtle glitch effects and smooth scroll animations using AOS
- **Interactive**: Alpine.js for interactive elements
- **Two Audiences**: Clear separation between B2B (Businesses) and B2C (Professionals) services

## Tech Stack

- HTML5
- Tailwind CSS (via CDN)
- Alpine.js (for interactivity)
- AOS (Animate On Scroll)
- Font Awesome (icons)

## Setup

No build step required! Simply open `index.html` in a browser.

## Deployment

Deployed on Vercel - automatically detects static site and deploys.
